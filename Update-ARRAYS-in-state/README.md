# React Food List 🍎

This is a React practice example for learning how to work with **arrays using the `useState()` Hook**.

The example allows the user to:

- ➕ Add new foods to a list
- 🗑️ Remove foods by clicking on them
- 📋 Display the food list dynamically
- 🔄 Update the array stored in React state

---

## 📚 Concepts Covered

- `useState()`
- Arrays in state
- Updating array state
- Functional state updates
- Spread operator (`...`)
- `.map()`
- `.filter()`
- `key`
- `onClick`
- Event handlers
- Arrow functions
- Callback functions
- Function parameters
- Array indexes
- `document.getElementById()`
- `.value`
